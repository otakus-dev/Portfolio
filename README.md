# Портфолио Андрея

Статический сайт-портфолио с отдельными страницами проектов.

## Структура

- `index.html` — главная страница портфолио;
- `styles.css` — оформление главной страницы;
- `script.js` — небольшие интерактивные элементы;
- `projects/ember/` — первый кейс, сайт кофейни EMBER.

Сайт готов для публикации через GitHub Pages без сборки.
