# Проверка портфолио

Сохранены композиции, палитры и шрифты существующих проектов.

Исправления:
- Лесной берег: единый SVG-знак с соснами и водой в шапке, подвале и вкладке
- Привилегия: размер длинного адреса на мобильной странице расположения
- EMBER: минимальная дата бронирования по местному времени
- Линия: счётчики без анимации при системной настройке уменьшения движения
- Модуль: сообщение подписки больше не обещает фактическую отправку письма
- Демонстрационные формы: понятные сообщения о пробном результате
- Все сайты: видимый фокус клавиатуры, закрытие меню по Escape,
  корректные клики внутри диалога, прокрутка длинных окон на телефоне

Автоматическая проверка охватывает HTML-страницы на двух ширинах,
изображения, якорные ссылки, ошибки JavaScript и выход текста за экран.
Отдельный сценарий проверяет подбор и расчёт проживания.

Что можно развивать позднее:
- Модуль: сохранение корзины между посещениями
- Привилегия: отдельные детальные планировки для каждой квартиры
- РТК: реальные тарифы и маршруты при работе с заказчиком
- Все кейсы: короткие описания задачи и решений для потенциальных клиентов

Эти расширения не входят в текущую косметическую правку.
